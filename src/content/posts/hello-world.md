欢迎来到我的个人博客。

这个站点使用 [Astro](https://astro.build/) 和 [AstroPaper](https://github.com/satnaing/astro-paper) 构建，并通过 GitHub Pages 自动发布。

以后我会在这里记录技术实践、学习笔记，以及生活中的思考。

## 写作方式

新文章放在 `src/content/posts/` 目录中，使用 Markdown 或 MDX 编写。提交并推送到 `main` 分支后，GitHub Actions 会自动构建和发布网站。
